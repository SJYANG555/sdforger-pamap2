\begin{frame}{Distance Ratio Interpretation for Filtered Results}
\small
\begin{itemize}
  \item Distance ratio is computed against a real-vs-real reference:
  \[
    \mathrm{ratio}=\frac{d(\mathrm{synthetic},\mathrm{real})}{d(\mathrm{real},\mathrm{real})}.
  \]
  \item For \textbf{chest gyro}, values far below 1.0 are not necessarily better: synthetic windows can become smoother or less diverse than real windows. Ratios closer to 1.0 are more interpretable.
  \item For \textbf{hand}, generated distances are still much larger than the real reference, so smaller ratios remain preferable.
  \item Reference distances: chest gyro ED=3.21, DTW=7.47; hand ED=46.66, DTW=61.03.
  \item ``Acc'' below is synthetic-only HAR accuracy. ``Valid'' is valid windows after filtering; no-filter rows use /305 prompts, filtered rows use /valid-generated before stats filtering.
\end{itemize}
\end{frame}

\begin{frame}{Accuracy vs. Distance-Ratio Trade-Off}
\small
\begin{itemize}
  \item \textbf{Chest gyro stats, ep5}: strict filtering improves accuracy from 0.449 to 0.921, but DTW/ref increases from 0.74 to 2.08.
  \item \textbf{Chest gyro stats ICA12, ep5}: strict filtering improves accuracy from 0.898 to 0.931, but DTW/ref increases from 0.83 to 2.20.
  \item \textbf{Hand stats, ep5}: strict filtering gives a small accuracy gain from 0.928 to 0.938; medium filtering gives the lowest DTW/ref among the filtered variants.
  \item \textbf{Hand stats ICA12, ep5}: filtering improves accuracy slightly to 0.934, but distance ratios do not consistently improve.
  \item Overall, stats-consistency filtering is useful for choosing better qualitative cases, but should not be claimed as universally improving waveform fidelity.
\end{itemize}
\end{frame}
